How I work with AI

I develop with Claude Code every day. AI makes me faster, so I use a process that keeps quality from dropping:

  1. Spec first. Every feature starts with a written spec before any code is written.
  2. The right model for each job. Cheaper models implement; the strongest model handles architecture and review.
  3. Test maps and gates. Each change ships with tests and passes automated gates before it can be pushed.
  4. Human review. I review every change before release.
